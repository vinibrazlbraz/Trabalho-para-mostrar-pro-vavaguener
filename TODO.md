# Entregas da atividade

## 1. Navegação e responsividade
- [x] A aplicação deve se adaptar a mobile com largura de até 768 px e desktop a partir de 769 px.
- [x] O cabeçalho deve possuir menu funcional e responsivo para Categorias, Produtos, Clientes e Pedidos.
- [x] As páginas devem estar integradas à navegação da aplicação.

## 2. Página Home
- [x] A Home deve apresentar o nome dos integrantes da dupla.
- [x] A Home deve apresentar um resumo visual com dados carregados da API.

## 3. Listar pedidos
- [x] A página Listar Pedidos deve exibir dinamicamente os pedidos cadastrados.
- [x] Cada pedido deve mostrar cliente, data, status e seus itens de pedido, compostos por produto e quantidade.

## 4. Criar pedido
- [x] A página Criar Pedido deve permitir selecionar um cliente.
- [x] A página Criar Pedido deve permitir adicionar produtos e suas respectivas quantidades.
- [x] O formulário deve enviar o pedido e os itens de pedido usando requisições HTTP.
- [x] A interface deve exibir estados de carregamento, sucesso e erro.

## 5. Integração com a API
- [x] Todos os registros devem ser carregados dinamicamente via Fetch API.
- [x] A aplicação deve utilizar https://stock.dev.vilhena.ifro.edu.br/api nas rotas /categorias, /produtos, /clientes, /pedidos e /itens_pedido.
- [x] Não devem ser usados dados fixos para representar registros cadastrados na API.

## 6. Organização
- [x] O código deve usar componentes e módulos simples, organizados por responsabilidade.
- [x] O código deve estar preparado para versionamento com Git.
